# 🌍 Hidden Horizons – Travel Website

**Explore Beyond Limits.**

Hidden Horizons is a modern and responsive travel website homepage designed using HTML and CSS. It helps users explore popular destinations, discover hotels, and find top-rated restaurants.

## ✨ Features

- Modern and clean user interface
- Responsive navigation bar
- Destination search section
- Price and rating filters
- Featured travel destinations
- Popular hotel listings
- Top-rated restaurants
- Mobile-friendly responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries

## 📁 Project Structure

```text
Hidden-Horizons/
│
├── index.html
├── style.css
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the website!

## 🎯 Project Purpose

This project was created to practice HTML and CSS skills and to build a modern, responsive travel website.
